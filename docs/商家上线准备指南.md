# 商家上线准备指南

这是一份给店主的执行清单。项目目前是演示环境；收真钱前必须按本文准备资料，再交给开发者接入。不要把身份证、银行卡、私钥、API Key 发到公开 GitHub、群聊或截图里。

## 一、先决定主体和收款账户

建议使用实际经营主体申请：有营业执照用个体工商户/企业，没有执照则先确认是否符合微信支付小微商户条件。准备：经营者身份证正反面、本人银行卡、银行预留手机号、店铺名称、店铺地址、经营类目、门头/店内照片、营业执照（如有）。结算银行卡必须能由经营者控制。

微信支付会按商户与类目核定费率。官方小微商户文档列出 0.38%–0.6% 多档费率；小程序接入指引提示常见经营类目约 0.6%–1%。以进件页面最终展示为准，不要按本文估算签约。

## 二、注册小程序

1. 用店主常用邮箱注册微信公众平台小程序账号，管理员绑定店主本人微信。
2. 选择与实际主体一致的认证类型，填写店名、经营范围和服务类目。
3. 完成微信认证、备案及小程序名称/头像/服务简介；上传隐私保护指引。
4. 把 AppID 交给开发者；AppSecret 只能放服务器密钥管理，不能发到 GitHub。

认证费会随主体和规则调整。个体工商户常见为 30 元/年、企业常见为 300 元/年；付款前以公众平台认证页为准。

## 三、申请微信支付并绑定小程序

1. 在微信支付商户平台或商家助手按“申请商户号/进件”填写主体、结算账户与经营资料。
2. 审核通过后，在商户平台把该商户号与小程序 AppID 绑定，并确认具备 JSAPI/小程序支付能力。
3. 创建商户 API 证书，保存商户号、证书序列号、私钥、API v3 Key；这些只交开发者安全录入部署平台 Secret。
4. 用一笔小额真实/测试订单验收：取消支付、支付成功、重复通知、金额不一致和查单补偿都要验证。

## 四、腾讯地图与配送范围

1. 注册腾讯位置服务，绑定手机号和邮箱，创建服务端 Key。
2. 把 Key 交开发者配置 IP/域名限制；不要放进小程序仓库。
3. 提供店铺完整地址、门头定位截图和经纬度（当前暂定 `106.98, 26.45`，上线前必须实测确认）。
4. 列出常送小区与边界地址，开发者逐个比对骑行距离；第一版配送费固定 2 元，之后再启用分档规则。

腾讯位置服务可申请 Key 并提供路线规划能力；套餐/免费额度与价格变动较快，请在控制台按实际调用量确认。

## 五、打印机与店内设备

选择支持云打印 API 的品牌，购买前确认支持：HTTP API、设备编号、服务端密钥、订单重打、中文小票。准备设备编号、厂商账号/API 凭据，并在店里接通稳定 Wi-Fi 与电源。小票模板至少包含订单号、菜品数量、地址、电话、备注、配送费、总额和支付状态。

## 六、上线前交付给开发者的信息

- 店铺名、营业时间、客服/接单电话、完整地址、店铺经纬度。
- 商品清单：名称、售价、分类、是否上架；第一版不需要商品图。
- 管理员手机号：`18785409634`、`18285424586`；正式上线后用微信登录绑定，不再手填手机号。
- 小程序 AppID、支付商户号、腾讯地图 Key、打印机设备编号。
- 云服务器账号由店主本人持有或建立可恢复的共同管理账号；准备域名、HTTPS、数据库每日备份联系人。

## 七、最终验收顺序

按真机依次测试：顾客选点/定位、门牌号和电话、配送费、取消支付、支付成功；商家新订单、改为制作中/待配送/完成；打印成功、断网打印失败与重新打印。最后检查非管理员不能进商家页，且订单历史金额与距离不会因日后规则修改而变化。
