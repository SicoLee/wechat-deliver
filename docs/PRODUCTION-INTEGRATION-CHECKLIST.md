# 真实服务接入清单

本项目当前是安全的开发演示：`APP_ENV=production` 会拒绝启动，不能把模拟支付、模拟地图或模拟打印带到真实收款环境。以下项目全部完成、复核并由你明确决定启用后，才解除该保护。

## 先由店主准备（不要提交到 Git）

- 微信小程序 AppID 和 AppSecret；AppSecret 只放服务器密钥管理，不放小程序代码。
- 微信支付商户号、商户 API 证书/私钥、证书序列号、32 字节 API v3 Key；商户号必须与小程序 AppID 完成绑定。
- 一个公网 HTTPS 域名；小程序后台将它加入 request 合法域名，微信支付通知地址也使用它。通知 URL 不带查询参数。
- 腾讯位置服务 Key（服务器 IP/域名白名单按腾讯控制台能力配置）。
- 云打印机品牌、设备编号、打印机 API 凭据，以及最终小票模板内容。
- PostgreSQL 的托管实例或服务器、数据库密码和自动备份方案。

把值写进服务器的密钥管理或部署平台 Secret，绝不写入 `.env.example`、小程序代码、截图、日志或公开仓库。公开仓库里只保留字段名和脱敏示例。

## 登录与商家权限

- 小程序用 `wx.login` 获取一次性 code，后端调用微信 `code2Session` 换取 OpenID；不要让小程序自行传入或伪造 OpenID。
- 后端建立自己的短期登录态（例如 HttpOnly/签名 token），不要把 `session_key` 下发给小程序。
- 用微信 `getPhoneNumber` 的一次性凭据在后端校验手机号后，才允许把白名单手机号绑定到该 OpenID。
- 删除/保持禁用开发期的 `X-OpenID` 和手填手机号绑定快捷方式。当前项目已把手填绑定限制在开发/测试环境。

## 微信支付

- 服务端调用 [JSAPI/小程序下单接口](https://pay.wechatpay.cn/doc/v3/merchant/4012791897)，为已创建但未支付的订单取得 `prepay_id`；小程序再调用 `wx.requestPayment`。
- 订单创建和“预下单”都复用同一个幂等键。当前订单创建已具备幂等键，后续支付下单也必须沿用这个原则。
- `wx.requestPayment` 成功只用于改善页面体验；订单状态仍只能由微信支付服务端通知验签、解密、金额/商户号/AppID核对后更新。
- 接收成功通知后尽快返回 HTTP 204，把打印放入既有 outbox worker；不要让小票机网络影响微信回调。
- 增加“查单补偿”定时任务：针对长时间 `PENDING_PAYMENT` 的订单向微信查单，补回可能遗漏的通知；同时设置合适的支付过期和关单策略。
- 每日下载并核对交易账单，至少记录差异告警和人工处理结果。

微信支付文档明确说明 `prepay_id` 有有效期、前端完成回调并不能替代服务端确认，且商户在没有收到通知时应查单确认；实现时以当日官方文档为准。

## 地图、地址与配送

- 保持小程序选点与腾讯路线 API 使用同一坐标体系；上线前用店铺、典型小区和边界地址逐一人工核对距离。
- 后端使用腾讯骑行路线的 `routes[0].distance`（米）保存为订单快照，绝不在历史订单页按新规则重算。
- 为腾讯 Key 设置限制；地图故障时维持当前的 503 可重试提示，不能回退为直线距离收费。
- 启用分档配送费之前，把每个区间、边界是否包含、超范围文案写给顾客看，并在测试环境覆盖边界订单。

腾讯路线服务提供骑行路线与距离字段；本项目的适配器已预留该接口和异常降级。

## 云打印和运行保障

- 为选定品牌实现一个 `Printer` 适配器，使用设备编号和服务端凭据；保留 `MockPrinter` 仅作测试。
- 真实打印失败要记录供应商响应、次数和下一次重试时间（不得记录顾客地址/电话），商家端继续显示“打印失败 / 重新打印”。
- worker 以单独容器运行并监控存活；数据库、API、worker 均接入日志和告警。
- PostgreSQL 每日备份，并至少演练一次恢复；部署升级先在测试库执行 Alembic 迁移。

## 上线验收

- 真机验证小程序登录、选点、定位授权、下单、取消支付、成功支付和重复点击。
- 用微信支付沙箱/测试条件（以商户平台当前能力为准）验证验签、通知重放、金额不一致和查单补偿。
- 验证无商家权限用户无法查看订单、改状态、商品管理或调用内部 worker 接口。
- 验证地图不可用、打印机离线、worker 重启、数据库重启都不会把已支付订单丢失或重复打印。
- 配置 HTTPS、备份、告警、日志保留期和隐私告知后，再由你确认解除 `APP_ENV=production` 的启动保护。
