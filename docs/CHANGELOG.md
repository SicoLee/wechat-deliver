# 变更日志

本项目按“一个完整且验证过的能力，一条 `main` 分支提交”维护。每条记录说明影响、验证方式和后续配置要求。

## [Unreleased]

### Added

- 后端核心订单流自动化测试和 GitHub Actions 持续集成。
- 支付交易标识、支付状态和持久化订单事件（transactional outbox）基础。
- Alembic 数据库版本迁移与首份不可变初始 schema。
- FastAPI lifespan 生命周期管理，移除弃用的启动事件注册方式。
- 请求关联 ID 与不记录请求体/查询参数的结构化运行日志。
- 生产环境启动保护：禁止携带模拟支付、地图与打印实现上线。
- 订单操作审计记录及商家查询接口。
- 顾客“我的订单”页面和可访问的商家入口。
- 下单载荷完整性校验（坐标边界、购物车上限和去重）。
- 商家订单页可见期间的 10 秒轻量轮询与下拉刷新。
- GitHub Actions 基础 Action 升级至当前主版本。
- CI 固定 Ubuntu 24.04，避免 `ubuntu-latest` 自动迁移改变构建环境。
- 非 root Docker 运行镜像、PostgreSQL 健康检查与迁移后启动部署流程。
- 商家商品新增、编辑和上下架 API。
- 腾讯地图骑行道路距离适配器与可切换配送距离提供方。
- 微信支付 API v3 回调验签、解密、金额核对与幂等支付确认服务。
- 受专用令牌保护的打印 outbox 调度接口。
- Docker Compose 常驻打印事件 worker。
- 配送费策略（默认固定费用，可配置道路距离分档与配送上限）。
- API 数据库就绪探针及基于它的容器健康检查。
- 小程序商家商品管理页面。
- 订单创建幂等键，避免网络重试或连点导致重复订单。
- 腾讯地图异常的安全降级响应，避免将供应商错误暴露给顾客。
- 结算页配送报价状态控制，报价失败或未完成时阻止提交订单。
- 限制开发用的商家手机号绑定接口，防止未来上线时将手机号误当作身份凭据。
- 商家订单页中文状态和按履约阶段筛选。
- 顾客订单详情页与仅本人可读取的订单详情 API。
- 真实微信支付、登录、地图、打印和部署的上线接入清单。
- 商家小程序商品管理页支持修改名称、售价和分类。
- 商家订单详情改为按订单读取，避免随订单量增长重复拉取完整列表。
- 打印 outbox 指数退避自动重试、最大尝试次数与失败终止状态。
- 云打印适配器异常隔离为可重试事件，避免 worker 因供应商网络错误退出。
- API 补打、内部调度与常驻 worker 统一采用同一套打印重试配置。
- 下单联系电话改为严格校验 11 位中国大陆手机号。
- 微信支付启动校验提前检查 API v3 Key 长度和平台证书文件。
- 健康检查准确报告实际支付和地图提供方，且不暴露配置密钥。
- 扩大订单编号随机段，降低同秒并发下的编号碰撞概率。
- 结算页联系电话输入与服务端 11 位手机号规则保持一致。
- production 显式拒绝开发用 `X-OpenID`，避免伪造身份头意外上线。
- CI 从空 SQLite 数据库执行完整 Alembic 迁移链。
- 小程序菜单与购物车启用统一的简洁视觉层级和紧凑数量控件。
- 结算页重构为地址优先、费用与备注次级、单一支付动作的简洁层级。
- 支付成功页和订单列表接入统一成功状态、订单状态徽标与扫读层级。
- 商家订单页接入横向状态筛选、订单卡片与工具区视觉层级。

### Verified

- 顾客创建订单、服务端支付回调幂等、商家可见、订单进入制作中。
- 未绑定商家身份不能读取商家订单。
- 同一个模拟支付回调重复到达时，只创建一次打印事件。
- CI 在干净工作目录中自行创建 SQLite 测试目录。
- 每个 API 响应均包含可用于排障的 `X-Request-ID`。
- `APP_ENV=production` 会明确拒绝启动，直到真实外部服务已接入。
- 订单状态变更和补打动作可保留操作者、前后状态与时间记录。
- 订单 API 拒绝重复商品和非法经纬度。
- 不完整的微信支付生产配置会被拒绝。
