# 单店微信点单

一个可演示、可逐步接入生产服务的单店微信小程序：顾客点单、地图地址、固定配送费、模拟支付、商家订单管理与模拟打印。

在开始前请阅读 [运行与测试指南](docs/RUNBOOK.md)；真实支付、地图和打印接入时按 [真实服务接入清单](docs/PRODUCTION-INTEGRATION-CHECKLIST.md) 逐项完成。
店主准备账号、资料和设备时请按 [商家上线准备指南](docs/商家上线准备指南.md) 执行。
持续维护记录见 [变更日志](docs/CHANGELOG.md)。每次推送 `main` 都会由 GitHub Actions 重新检查后端编译、订单流程测试和小程序 JavaScript 语法。

## 项目结构

```text
miniprogram/   微信小程序原生前端（导入微信开发者工具）
server/        FastAPI API（PostgreSQL/SQLite 均可）
docs/          部署和替换真实服务的说明
```

## 1.0 的明确边界

- 配送费固定 ¥2；道路距离仅展示与入库，为后续计费做准备。
- 开发环境采用模拟骑行距离、模拟支付回调、模拟云打印。
- 只有服务端“支付成功回调”会把订单改为已支付并触发打印；前端不会自行确认订单。
- 开发期可用白名单手机号快捷绑定；正式版必须由微信登录和后端校验的一次性手机号凭据绑定。

正式接入前必须替换为：腾讯地图骑行距离、完整微信支付下单/回调/查单、云打印机 API、微信登录与手机号校验、订阅消息和 PostgreSQL。
