# 单店微信点单

一个可演示、可逐步接入生产服务的单店微信小程序：顾客点单、地图地址、固定配送费、模拟支付、商家订单管理与模拟打印。

在开始前请阅读 [运行与测试指南](docs/RUNBOOK.md)。

## 项目结构

```text
miniprogram/   微信小程序原生前端（导入微信开发者工具）
server/        FastAPI API（PostgreSQL/SQLite 均可）
docs/          部署和替换真实服务的说明
```

## 1.0 的明确边界

- 配送费固定 ¥2；道路距离仅展示与入库，为后续计费做准备。
- 开发环境采用模拟骑行距离、模拟支付回调、模拟云打印。
- 只有服务端“支付成功回调”会把订单改为已支付并触发打印；前端不会自行确认订单。
- 商家由微信授权手机号绑定，默认白名单见 `server/.env.example`。

正式接入前必须替换为：腾讯地图骑行距离、微信支付回调验签、云打印机 API、订阅消息和 PostgreSQL。
